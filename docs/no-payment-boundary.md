# حدود عدم الدفع في DevForge

تعمل وظائف DevForge الأساسية، مثل مساحات العمل والمراجعات والمجتمع ومحطة JavaScript والمراكز الخاصة بالمالك، دون عرض نموذج دفع أو اشتراك أو إدخال بطاقة داخل المنصة.

| المجال | الحالة الحالية |
| --- | --- |
| Stripe | أزيل مساره وواجهة مختبره ومواد الاختبار من المشروع. لا توجد جلسة دفع أو ويبهوك أو مفتاح Stripe مفعّل. |
| التنقل | لا يظهر مدخل Stripe أو مدفوعات أو اشتراكات في قائمة المالك. |
| كتالوج التكاملات | لا تظهر بطاقة Stripe أو فئة مدفوعات. تبقى المنصات الخارجية اختيارية ولا تُنشأ حسابات أو عمليات مالية تلقائيًا. |
| البيانات المالية | لا تجمع الواجهة رقم بطاقة أو معلومات فوترة أو بيانات دفع. |

> إذا اختار المالك مستقبلًا إضافة مدفوعات، فستكون مهمة منفصلة تتطلب موافقة جديدة، وتحديد منتجات وأسعار، وإعداد مفاتيح خادم آمنة، ومراجعة قانونية وتشغيلية. لا يستنتج DevForge هذه الموافقة من هذا الإصدار.
