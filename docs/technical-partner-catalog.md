# دليل الشركاء التقنيين

يعرض DevForge هذه الجهات باعتبارها **مصادر تقنية مرشحة** لا شراكات تجارية قائمة. لا يعني أي مدخل أن الحساب متصل أو أن بيانات المنصة تُرسل إليه.

| الجهة | المجال | وضع DevForge |
|---|---|---|
| GitHub | شفرة ومستودعات | طلب مراجعة فقط، ولا استيراد أو كتابة تلقائية. |
| Supabase | بيانات وهوية وتخزين | إرشاد وطلب مراجعة فقط، ولا مفاتيح خدمة أو بيانات صفوف. |
| Sentry | مراقبة وتشخيص | طلب قراءة مقيدة بعد تفويض مستقل؛ لا تغيير للتنبيهات أو الإعدادات. |
| Replit | تطوير سحابي | طلب مراجعة فقط؛ لا إنشاء مساحة أو تنفيذ كود تلقائي. |
| OpenAlex وCrossref | معرفة وأبحاث مفتوحة | نتائج عامة للقراءة فقط في مركز البحث العالمي. |

تعتمد بطاقات الدليل على الوثائق الرسمية للمزودين: [GitHub REST API](https://docs.github.com/en/rest)، [Supabase Docs](https://supabase.com/docs)، [Sentry Docs](https://docs.sentry.io/)، [Replit Integrations](https://docs.replit.com/features/integrations/overview)، [OpenAlex Help](https://help.openalex.org/)، و[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/).
