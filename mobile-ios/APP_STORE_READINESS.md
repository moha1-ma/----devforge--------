# جاهزية App Store لتطبيق DevForge

## ما يمكن إنجازه داخل المصدر الآن

يمكن تجهيز تجربة iPhone، هوية التطبيق، تنقل التعليم وسوق المواقع، ووثائق بيانات المتجر. لا يتضمن ذلك إنشاء IPA موقّع أو رفع build أو تقديم مراجعة؛ فهذه إجراءات خارجية تتطلب حساب Apple Developer وApp Store Connect وقرار المالك النهائي.

يستخدم هذا الإصدار رابط HTTPS قابلًا للتهيئة عبر `EXPO_PUBLIC_DEVFORGE_ORIGIN` بدلًا من الاعتماد على رابط أي مشروع آخر. لا يبدأ التطبيق فتح مساحة العمل إن لم يكن رابط النسخة المستقلة مضبوطًا، ويقيد متصفح الويب المدمج بمنصة DevForge المحددة وصفحات تسجيل الدخول الرسمية.

## حدود المنتج المقترح

| المجال | ما يدعمه الإصدار الحالي | ما لا يدعيه أو ينفذه تلقائيًا |
|---|---|---|
| التعليم | مسارات إرشادية وأدوات بناء داخل DevForge | لا يعتمد تصنيف Kids ولا يدعي اعتمادًا تعليميًا رسميًا. |
| سوق المواقع | كتالوج مواقع/نطاقات ومشروعات شفافة | لا قوائم بيع مفبركة، ولا تقييمات، ولا توافر أو ملكية نطاقات مؤكدة، ولا تحصيل مدفوعات. |
| الحساب والبيانات | مصادقة داخل صفحة DevForge الرسمية وسجل خاص بالمالك | لا يحتفظ تطبيق iOS بكلمات مرور أو رموز مالك أو مفاتيح خدمات. |
| النشر | مصدر Expo وmetadata ووثائق مراجعة | لا توقيع أو TestFlight أو رفع App Store Connect أو إرسال للمراجعة. |

## القيمة الأصلية قبل الإرسال

يتضمن التطبيق واجهة iPhone أصلية، اختصارات أدوات، وحفظ موجز بناء خاص على الجهاز عبر التخزين المحلي مع تحكم حذف صريح. لا يُرسل الموجز إلى DevForge أو إلى طرف ثالث تلقائيًا. ومع ذلك، لا يضمن ذلك قبول App Review؛ تنص Apple على أن محتوى الويب داخل تطبيق iOS أو التفاعلات المحدودة لا تمثل تجربة تطبيق عالية الجودة بذاتها. قبل الإرسال يجب اختبار كل تدفق فعليًا وتقديم وصف ولقطات شاشة صادقة تبرز الوظائف الأصلية، لا متصفح الويب المضمن فقط.

## متطلبات المالك قبل الإرسال

1. حساب Apple Developer ومالك قانوني لـ bundle identifier `com.devforge.platform`.
2. بناء موقّع واختبار فعلي على iPhone، ثم رفعه عبر Xcode أو خدمة بناء يختارها المالك.
3. صفحة متجر مكتملة: الاسم، الوصف، التصنيف، الكلمات المفتاحية، لقطات من تجربة حقيقية، رابط دعم، ورابط سياسة خصوصية عام.
4. بيانات خصوصية دقيقة في App Store Connect لكل بيانات يجمعها التطبيق أو SDKs أو صفحة الويب المضمنة.
5. إذا نُشر محتوى أو قوائم من المستخدمين/المبدعين، تضيف المنصة قبل الإطلاق آليات تصفية وإبلاغ وحظر ودعم كما تتطلب مراجعة المحتوى الذي ينشئه المستخدم.
6. إذا تم تفعيل دفع لمنتجات رقمية داخل التطبيق، يُراجع مسار الدفع وسياسات Apple قبل الإعلان عنه أو تقديمه.
7. رابط دعم عام بمعلومات اتصال محدثة ورابط سياسة خصوصية عامة ودقيقة. لا يُنشأ أي منهما باسم المالك أو ببيانات اتصال غير معتمدة.

## ما هو مجاني وما ليس كذلك

| المسار | التكلفة/الشرط | النتيجة |
|---|---|---|
| التطوير والاختبار الشخصي | Apple Account وXcode أو Expo Go | تشغيل على أجهزة محدودة للاختبار، مع انتهاء provisioning المجاني دوريًا. |
| إعفاء الرسوم | للمنظمات غير الربحية المؤهلة أو المؤسسات التعليمية المعتمدة أو الجهات الحكومية، بعد موافقة Apple | قد يجعل عضوية Apple Developer مجانية للمؤهلين. |
| TestFlight وApp Store العام | Apple Developer Program وApp Store Connect | يتطلب عادةً عضوية Apple Developer مدفوعة؛ لا يُنفذ قبل تأكيد المالك. |

> لا تُدخل الهوية أو الدفع أو بيانات الضرائب أو توافق على اتفاقيات Apple أو ترسل التطبيق للمراجعة إلا في جلسة يسيطر عليها المالك وبعد تأكيد صريح لكل خطوة.
