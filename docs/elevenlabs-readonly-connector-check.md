# فحص موصل ElevenLabs للقراءة فقط

فُحص إعداد الموصل في الجلسة. الموصل باسم **ElevenLabs** مفعّل، بينما موصل **ElevenLabs API** منفصل وغير مفعّل. لم تُعدَّل الإعدادات ولم يُنشأ صوت أو وكيل أو ملف صوتي.

| خطوة القراءة | النتيجة | الأثر |
| --- | --- | --- |
| سرد الأدوات | نجح | ظهرت أدوات قراءة مثل `list_models` و`search_voices` و`get_voice` و`list_agents` و`list_conversations`. |
| فحص مخطط `list_models` | نجح | الأداة لا تستقبل مدخلات محددة ومصنفة قراءة فقط. |
| استدعاء `list_models` | تعذر | فشل الموصل قبل إرجاع البيانات بخطأ ترميز ASCII للحرف المخفي `U+202A`. |
| فحص ثم استدعاء `list_agents` | تعذر | فشل بنفس خطأ الترميز قبل إرجاع بيانات الحساب. |

الخلل يقع في طبقة الموصل قبل الحصول على أي قائمة، ولذلك لا توجد نماذج أو وكلاء أو بيانات حساب يمكن تلخيصها بأمان. لم تُجرَ محاولة ثالثة من أداة مختلفة لتجنب الاستدعاءات غير الضرورية؛ يلزم إصلاح ترميز الموصل أو إعادة تفويضه من واجهة الموصل قبل إجراء تحقق قراءة جديد.

> لا يتضمن هذا الفحص أي إنشاء صوت أو استنساخ صوت أو توليد موسيقى أو تحويل صوت أو إنشاء وكيل.
