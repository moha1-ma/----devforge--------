# حدود إشعارات DevForge داخل الموقع

يركز هذا الإصدار على **إشعارات داخل الموقع** فقط. لكل إشعار مستلم محدد، وفئة، وعنوان، ومحتوى محدود، ورابط داخلي معتمد اختياري، وحالة قراءة. لا تُعرض الإشعارات إلا لصاحبها ولا تُنشأ من بيانات تجريبية أو محتوى مصطنع.

| النطاق | متاح | غير متاح في هذا الإصدار |
| --- | --- | --- |
| عرض الإشعارات | مركز خاص بالمستخدم أو المالك مع حالة القراءة | كشف نشاط مستخدمين آخرين. |
| التفضيلات | تشغيل الإشعارات داخل الموقع وفئاتها للمالك | إرسال بريد أو SMS أو إشعار جهاز أو Web Push. |
| الأحداث | إشعار حقيقي للمالك عند مشاركة زائر جديدة خاضعة للمراجعة | محتوى تسويقي أو نوافذ منبثقة أو رسائل خارجية تلقائية. |
| الخصوصية | روابط داخلية ثابتة ومحتوى مقيد الطول | أسرار أو رموز جلسات أو عناوين خارجية غير معتمدة. |

أي قناة خارج الموقع تحتاج إعدادًا وموافقة منفصلين، ولا تُفعل عبر هذا المركز تلقائيًا.

## تحقق الوصول

فُتح المسار `#/notifications` دون جلسة في بيئة المعاينة. بعد اكتمال التحميل ظهر حاجز تسجيل الدخول الخاص بـ DevForge فقط، ولم تُعرض الإشعارات أو التفضيلات أو أي محتوى للمستلم.
