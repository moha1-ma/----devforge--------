# JavaScript والخدمات الاختيارية

تظل وظائف DevForge الأساسية داخل المنصة، ومنها مساحة العمل والمراجعات والمجتمع ومحطة JavaScript المحلية، منفصلة عن أي إعداد دفع أو حساب مالي. لا تنشئ DevForge عملية دفع أو اشتراكًا أو حسابًا خارجيًا، ولا ترسل رمز وصول أو كودًا إلى مزود خارجي لمجرد فتح صفحة الكتالوج.

| المسار | الوضع في DevForge | ملاحظة التكلفة والاتصال |
| --- | --- | --- |
| محطة JavaScript الداخلية | تنفيذ محلي معزول ومحدود | لا تتطلب ربط مزود خارجي؛ ولا تصل إلى ملفات المنصة أو الأسرار أو الشبكة. |
| Replit وStackBlitz وCodeSandbox | روابط توثيق وخيار طلب مراجعة فقط | يحدد كل مزود طبقته أو تسعيره بنفسه، ولا ينشئ DevForge مساحة أو مشروعًا أو حسابًا. [1] [2] [3] |
| CodePen وJSFiddle وDeno Playground | مراجع اختيارية لتجارب الويب | لا يرسل DevForge الكود إلى أي منها ولا ينشر نتيجة أو رابطًا تلقائيًا. [4] [5] [6] |
| المدفوعات والتحويلات | غير مفعلة | لا حسابات مالية، ولا بطاقات، ولا تحويلات، ولا مفاتيح دفع داخل DevForge. |

> تصنيف **خيار مجاني أو طبقة مجانية** هو وصف إرشادي قابل للتغير لدى المزود، وليس ضمانًا لاستمرارية الخدمة أو حدود استخدامها. يبقى فتح أي حساب أو اختيار خطة أو تفعيل اتصال إجراءً منفصلًا يوافق عليه المالك لدى المزود.
