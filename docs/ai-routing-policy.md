# سياسة موجّهات الذكاء الصناعي

## الغرض

يوجّه DevForge مهمة المالك إلى مساحة العمل المناسبة، ويقسّمها إلى مسارات مراجعة صغيرة وواضحة. لا ينفذ الموجّه الشيفرة، ولا يغيّر ملفات المنصة، ولا ينشر، ولا يفتح حسابات أو يصل إلى حسابات خارجية من دون تفويض صريح ومحدّد.

| فئة المهمة | توصية DevForge | المخرج |
| --- | --- | --- |
| تحسين شيفرة خاصة | مساحة الكود وتشخيص الملف | اقتراح إصلاح يدوي فقط |
| بحث أو توثيق | البحث الموثق أو مركز البحث العالمي | روابط مصدر وملخص قابل للمراجعة |
| بنية موقع أو تطبيق | مركز المطور وخطة البناء | مراحل، مخاطر، واختبارات مقترحة |
| تكامل خارجي | مركز التكاملات | حالة اتصال ودليل رسمي، لا مفتاح مخزن في الواجهة |
| تشغيل JavaScript تجريبي | محطة JavaScript الخاصة | تشغيل محلي محدود ومعزول، لا شبكة أو أسرار |

## فئات المصادر الموثقة

يعرض الموجّه روابط توثيق رسمية لمزودين محتملين ولا يعني العرض أن هناك اتصالًا نشطًا أو موافقة على مشاركة البيانات. توثق منصات OpenAI وClaude وGemini واجهات وأدوات للمطورين، لكن ربط أي منها يحتاج إلى مسار رسمي وصلاحية محددة يديرها المالك [1] [2] [3].

> لا يختار الموجّه مزودًا نيابة عن المالك ولا يرسل المحتوى الخاص إلى مزود خارجي في الخلفية.

## حدود السرعة والأمان

يعمل «موجّه المهام» على تصنيف محلي صغير ومدخل محدود الحجم، ثم يعرض مسارات مستقلة لتقليل التشويش وتسريع قرار المالك. ولا يعد ذلك بحاسوب ذاتي التحكم أو تشغيل متوازٍ غير محدود. أي عمل دوري يظل مسودة مراجعة مجدولة ومحددة، وأي تكامل خارجي يبقى للقراءة افتراضيًا حتى يوافق المالك على نطاقه.
