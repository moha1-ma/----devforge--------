# حدود المحطات المصغرة في DevForge

تتكون لوحة المالك من **عشر محطات ثابتة** ذات أدوار هندسية متمايزة. لا تعد هذه المحطات نسخًا من جهاز أو نظام تشغيل، ولا تنشئ محطات جديدة، ولا تعمل في الخلفية، ولا تغير الشيفرة أو البنية أو الحسابات من تلقاء نفسها.

| القدرة | مسموحة عند طلب المالك | غير مسموحة |
| --- | --- | --- |
| التحليل | إنتاج نتيجة منظمة مرتبطة بالدور المحدد | ادعاء تنفيذ تغيير أو اختبار أو نشر فعلي. |
| ذاكرة المسار | حفظ الطلب والمخرج والمصدر الزمني وحالة المراجعة داخل مساحة المالك | حفظ أسرار أو رموز جلسات أو بيانات حسابات خارجية. |
| GitHub | تجهيز مخرج للمراجعة أو ربطه بمستودع اختاره المالك مستقبلًا | إنشاء مستودع أو نسخه أو مزامنته أو الكتابة إليه تلقائيًا. |
| التجميع | اقتراح مسودة تجميع بعد طلب صريح من المالك | دمج الشيفرة أو حذف المحطات أو تغيير البنية تلقائيًا. |

تعمل كل محطة عند ضغط المالك لبدء مراجعة محددة؛ لا يوجد تشغيل دائم أو تكرار ذاتي. وتبقى نتيجة كل تشغيل **مراجعة فقط** حتى يتخذ المالك إجراءً منفصلًا خارج هذه المحطة.

## تحقق الوصول

فُتح المسار `#/mini-workstations` في بيئة المعاينة دون جلسة. ظهرت بوابة DevForge لتسجيل الدخول فقط، ولم تُعرض المحطات أو ذاكرة المسارات أو نتائج الذكاء، ولم يبدأ أي تشغيل.
