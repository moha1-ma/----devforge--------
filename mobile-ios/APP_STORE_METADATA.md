# مسودة بيانات App Store — DevForge

هذه مسودة مراجعة وليست بيانات منشورة أو مدفوعة. يجب على المالك التحقق من الاسم والتصنيف والروابط وبيانات الخصوصية قبل إدخالها في App Store Connect.

| الحقل | المسودة |
|---|---|
| الاسم | DevForge |
| العنوان الفرعي | تعلّم بناء المواقع من هاتفك |
| التصنيف المقترح | التعليم (الرئيسي)؛ الإنتاجية أو الأعمال بعد التحقق من تجربة السوق |
| وصف مختصر | خطّط وابدأ موقعك وتابع كودك ومشروعاتك من مساحة DevForge الخاصة. |
| تجربة السوق | معرض شفاف لمشروعات ومقترحات نطاقات المالك، بلا وعود بيع أو توفر أو دفعات داخل التطبيق. |
| الخصوصية | تسجيل الدخول داخل موقع DevForge؛ لا يخزّن تطبيق iOS كلمة مرور أو رمز مالك أو مفاتيح خدمات محليًا. يظل إعلان الخصوصية النهائي مرهونًا بما تجمعه المنصة أو WebView فعليًا. |
| لقطات الشاشة | يجب أخذها من التطبيق الفعلي أثناء استخدام خطط البناء وWebsite Studio ومساحة الكود، لا من شاشة تحميل أو قالب. |
| رابط الدعم | يحتاج رابط دعم عام يحدده المالك قبل الإرسال. |
| سياسة الخصوصية | يحتاج رابط سياسة خصوصية عام ودقيق يحدده المالك قبل الإرسال. |

> لا تنشئ هذه المسودة قائمة سوق عامة، ولا مراجعات، ولا أسعارًا، ولا وسائل دفع، ولا تقرّ بتوفر أو ملكية أي موقع أو نطاق.
