# DevForge for iOS

هذا مشروع **Expo / React Native** لتطبيق DevForge المرافق على iPhone. يقدم شاشة أصلية عربية للملاحة السريعة ثم يفتح مساحة DevForge المنشورة داخل متصفح مدمج. تظل المصادقة وإدارة جلسة المالك ضمن موقع DevForge الآمن؛ لا يحفظ التطبيق كلمة مرور أو رمز ملكية أو مفتاح API.

## النطاق الحالي

| المتاح الآن | غير مشمول تلقائيًا |
|---|---|
| لوحة هاتفية أصلية، اختصارات للمساعد وWebsite Studio والنطاقات ومساحة الكود، وسياق جلسة الويب داخل التطبيق | ملف IPA موقّع، TestFlight، أو نشر App Store؛ تتطلب هذه الخطوات حساب Apple Developer وتوقيع المالك |

## التجربة على iPhone

ثبّت تطبيق **Expo Go** من App Store، ثم شغّل المشروع محليًا عبر `npm start` وامسح رمز QR من كاميرا الهاتف أو Expo Go. عند فتح مساحة العمل في التطبيق، سجل الدخول في صفحة DevForge نفسها باستخدام البريد ورمز المالك؛ لا تضع أي كلمة مرور أو رمز تحقق في مصدر التطبيق أو في المحادثة.

## إنشاء حزمة iOS لاحقًا

يتطلب إنشاء IPA/TestFlight حساب Apple Developer، ومعرّف Bundle مسجّلًا باسم المالك، وشهادات توقيع. قبل أي بناء موزّع، استبدل `ios.bundleIdentifier` في `app.json` بمعرّف تملكه فعليًا ثم نفّذ البناء الموقّع ضمن حساب Apple الخاص بك.

## أوامر المشروع

```bash
npm start
npm run ios
npx tsc --noEmit
```
