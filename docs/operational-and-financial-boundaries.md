# حدود التشغيل والطرفية والمدفوعات

## التشغيل المستمر

تعمل مسودات DevForge الدورية من خلال مهمة مجدولة مقيّدة، وتنتج مقترحات مراجعة فقط. لا تعتمد المنصة على عملية خفية تعدّل الشيفرة أو تنشرها أو تتصل بحسابات المستخدم من تلقاء نفسها. ويظل تشغيل الطرفية على الهاتف خارج المنصة إلى أن يربط المالك جهازه صراحة ويمنح جلسة محددة المدة والنطاق.

Termux هو بيئة طرفية ولينكس على Android، لكنه لا يمنح DevForge وصولًا إلى الهاتف أو ملفاته بذاته [1]. لذلك لا ينشئ DevForge خادم وصول بعيدًا أو مفاتيح SSH أو مهامًا دائمة على الهاتف. أي تكامل مستقبلي يجب أن يكون ذا اقتران ظاهر للمالك، وصلاحيات أقل قدر ممكن، وزمن انتهاء، وسجل تدقيق، وزر إلغاء فوري.

## الحدود المالية

لا يكفي البريد الإلكتروني لفتح حساب مالي أو تجاري عالمي. تذكر PayPal أن فتح حساب الأعمال يتطلب اسمًا قانونيًا وبريدًا وكلمة مرور وبيانات ضريبية ووصفًا للنشاط وبيانات حساب مصرفي [2]. وقد يتطلب التحقق التنظيمي بيانات شخصية أو بيانات الشركة ووثائق هوية وإثبات عنوان، وقد يشمل تحققًا حيويًا [3].

لذلك لا تنشئ DevForge حسابات مصرفية أو حسابات PayPal، ولا تحفظ هويات أو وثائق أو كلمات مرور أو رموز تحقق، ولا تبدأ تحويلات. عند تفعيل المدفوعات مستقبلًا، يقتصر دور المنصة على تقديم مسار تكامل رسمي يفتحه المالك بنفسه مع المزود، بعد مراجعة قانونية وتجارية، وبصلاحية محددة لا تسمح إلا بالوظيفة المطلوبة.

| النطاق | الحالة الحالية | الحماية |
| --- | --- | --- |
| مسودات التطوير | متاحة بالمراجعة فقط | لا كتابة أو نشر تلقائي |
| Termux أو طرفية الهاتف | غير متصل | لا وصول بعيد أو مفاتيح أو أوامر دائمة |
| السوق | أساس فارغ ومراجعة متجر | لا منتجات أو مدفوعات أو تقييمات مصطنعة |
| مدفوعات أو تحويلات | غير مفعلة | لا حسابات أو بيانات هوية أو تحويلات |
