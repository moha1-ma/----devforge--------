# ملخص اختبار Bright Data — قراءة فقط

## النتيجة

تم التحقق من الموصل المصرح به بعد اكتمال التفويض، ثم نُفذ اختبار بحث قراءة فقط عبر Google بالاستعلام: `OpenAI web search API official documentation`. أعاد الاختبار نتائج مرتبة تتضمن وثائق OpenAI الرسمية، ومنها صفحة **Web search | OpenAI API**، مع العنوان والرابط والوصف المختصر. لم تُكتب أي بيانات في خدمة خارجية ولم تُنشر أي محتويات.

## القدرات المتاحة في الجلسة

| القدرة | الحالة | حد الاستخدام في DevForge |
|---|---|---|
| البحث عبر Google أو Bing أو Yandex | متاح للقراءة فقط في جلسة Manus | لا يستدعيه الموقع تلقائيًا ولا يحفظ رموز الموصل. |
| البحث الدفعي | متاح للقراءة فقط | يستخدم فقط عند طلب بحث واضح ومحدود. |
| استخراج صفحة واحدة أو عدة صفحات كـ Markdown | متاح للقراءة فقط | يخضع لسياسة المصادر والحقوق؛ لا يستخدم لتجاوز الوصول الخاص. |
| مساعد إعداد Bright Data | متاح للشرح فقط | لا يغير الحساب أو الخطة أو إعدادات الموصل. |

> هذا الموصل متاح لجلسة الوكيل بعد تفويض المالك، وليس تكاملًا خادميًا مباشرًا داخل DevForge. لذلك لا تعرض واجهة الموقع هذا المصدر كأنه متصل، ولا تدّعي أن المساعد بحث الويب ما لم ينفذ مسارًا مصرحًا به ويعرض مصادره بوضوح.
