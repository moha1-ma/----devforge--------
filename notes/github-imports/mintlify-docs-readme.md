# سجل استيراد GitHub — Mintlify README

تم تنفيذ هذا الاستيراد بناءً على تفويض المالك الصريح باستخدام ربط GitHub المصرح به. اختير ملف README عام منخفض الحساسية من المستودع `elazzouz-dotcom/mintlify-docs` على الفرع `main`، ثم حُفظ في مساحة مصدر DevForge الخاصة بالمشروع تحت المسار `github-imports/mintlify-docs/README.md`.

| البند | النتيجة |
|---|---|
| نوع الملف | Markdown نصي (`README.md`) |
| طريقة النقل | قراءة فقط من GitHub ثم حفظ خاص عبر سياسة ملفات DevForge |
| عمليات على GitHub | لا كتابة، لا دفع تغييرات، لا workflow، ولا مزامنة لاحقة |
| سياق المساعد | اسم المستودع والفرع فقط، عند اختيار المالك له صراحة |
| التحقق | الإجراء المحمي `githubWorkspace.verifyImport` يتحقق عبر المستخدم المصادق عليه من سجل الملف وسجل GitHub في المشروع نفسه |

> لا يدّعي هذا السجل وجود مزامنة حية مع GitHub. أي استيراد لاحق يتطلب تفويضًا صريحًا جديدًا. لا يعتمد التحقق الدائم على نصوص مؤقتة أو على متغيرات هوية البيئة.
