# حدود منشئ المواقع والنطاقات في DevForge

ينشئ Website Studio مشروعًا خاصًا وملفات HTML وCSS وJavaScript وMarkdown قابلة للتحرير داخل مساحة المالك. الملفات تُخزَّن ضمن سياسة ملفات المصدر الخاصة ولا تُنفذ على الخادم؛ المعاينة المتاحة في محرر الكود مقيدة ببيئة متصفح معزولة.

يستقبل مركز النطاقات اسم نطاق مقترحًا للتحضير فقط، ويعرض حالة التحقق المطلوبة. لا يعني حفظ الاسم أن النطاق متاح أو محجوز أو مسجّل. تسجيل أو شراء نطاق يتطلب جهة تسجيل خارجية وشروط أهلية ورسومًا محتملة، وقد يستلزم بريدًا إلكترونيًا أو رقم هاتف وفق البلد. لا يجمع DevForge بيانات الدفع أو الهوية، ولا يبدأ عملية شراء أو يغيّر سجلات DNS دون اختيار المالك وتنفيذه الصريحين.

يستطيع المالك بعد إنشاء الموقع تحرير الملف، ربط نطاق يملكه لاحقًا من خلال إعدادات النطاقات في بيئة الاستضافة، أو تصدير الملفات لاستخدامها لدى أي مزود استضافة. لا توجد في هذه المرحلة وعود بتسجيل نطاق تلقائي أو إصدار تطبيق جوال أصلي أو تنفيذ كود المستخدم على الخادم.
