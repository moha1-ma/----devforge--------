# مصادر وضع البحث المعرفي في مساعد DevForge

## قرار التصميم

سيكون البحث **اختياريًا لكل رسالة**، للقراءة فقط، ولا يبدأ في الخلفية. سيعرض المساعد حالة المصدر وروابط الاستشهادات عند توافرها، ولن يخزّن مفاتيح مزودي البحث أو محتوى نتائج البحث الخام داخل DevForge إلا إذا اختار المالك لاحقًا ميزة حفظ مستقلة ومحددة.

| المصدر | ما يدعمه رسميًا | ملاءمته للمنصة | الحد المطبق في DevForge |
|---|---|---|---|
| OpenAI Web Search | بحث ويب داخل Responses API مع استشهادات وروابط ومصادر قابلة للعرض | يحتاج مفتاح OpenAI وتكلفة مستقلة؛ ليس مفعلًا تلقائيًا | لا يُنشأ موصل ولا يُرسل طلب حتى تفويض المالك وتهيئة آمنة منفصلة. |
| Perplexity Search API | نتائج ويب مرتبة في JSON مع تصفية نطاقات ولغة ومنطقة واستخراج محتوى | مناسب لمزوّد نتائج منفصل يحتاج مفتاح API | لا يُخزَّن المفتاح في قاعدة بيانات DevForge ولا يُستدعى إلا بعد اختيار المصدر صراحة. |
| Brave Search API | نتائج ويب ونصوص وسياق مهيأ للنماذج عبر فهرس مستقل | يحتاج مفتاح API وخطة استخدام | لا يُفعل أو يُستدعى قبل موافقة ومفتاح يهيئه المالك خارجيًا. |
| Tavily | بحث واستخراج وسياق حي موجه للوكلاء مع طبقات حماية | يحتاج حساب/API key مستقل | يظل خيارًا مقترحًا فقط؛ لا ربط شامل أو تخمين أسرار. |
| Bright Data عبر جلسة Manus | بحث Google/Bing/Yandex واستخراج صفحات ضمن موصل الجلسة المصرح به | يعمل داخل جلسة Manus فقط بعد التفويض؛ لا يزوّد خادم DevForge المنشور برمز وصول | تم اختبار بحث قراءة فقط عن وثائق OpenAI الرسمية بنجاح؛ لا يستدعيه موقع DevForge ولا يخزّن نتائجه أو رموزه. |

## متطلبات الواجهة

1. يختار المالك «بحث بمصادر موثوقة» لكل رسالة ولا يصبح افتراضيًا.
2. تعرض الواجهة بوضوح ما إذا كان البحث غير مهيأ، أو جرى عبر مصدر محدد، أو تعذر بسبب غياب التفويض.
3. لا توهم الواجهة بأن جميع محركات البحث أو جميع نماذج الذكاء الاصطناعي متصلة.
4. لا يسمح وضع البحث بنشر أو تعديل أو إرسال بيانات إلى خدمات خارجية.
